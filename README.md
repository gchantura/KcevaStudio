# Kceva Music Generator Studio

Browser-based music production with synthesizers, beats, recording, mixing, and multi-track arrangement.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
